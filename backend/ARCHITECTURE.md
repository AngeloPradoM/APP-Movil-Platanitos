# Backend de Platanitos

Esta carpeta contiene la futura implementación del backend REST de Platanitos.

Estado inicial:

- No hay conexión a una base de datos.
- No hay autenticación real implementada.
- El frontend continúa funcionando con datos simulados.

Dirección arquitectónica aprobada:

- NestJS y TypeScript.
- API REST documentada con OpenAPI.
- PostgreSQL.
- ORM con migraciones y consultas tipadas.
- Access tokens y refresh tokens rotativos para correo y contraseña.

Google, Apple, recuperación de contraseña, pagos y tracking permanecerán demostrativos hasta definir sus integraciones reales.
